Política de Privacidade — Critério Tech

Última atualização: 16 de novembro de 2026

1. Sobre o aplicativo e o site

O projeto Critério Tech (zenostech.com.br/criteriotech) reúne comparativos técnicos objetivos de tecnologia, áudio, hardware e eletrônicos, publicados em vitrine web e nos canais oficiais do projeto no Instagram, YouTube e TikTok.

2. Uso de dados e integrações (OAuth / APIs oficiais)

A integração com serviços de terceiros — incluindo Google / YouTube Data API v3, Meta Graph API (Instagram) e TikTok Content Posting API — é utilizada exclusivamente pela conta administradora proprietária do projeto Critério Tech para automatizar a publicação de vídeos e metadados nos seus próprios canais oficiais.

O site vitrine não solicita cadastro, não cria contas de usuários visitantes e não coleta, vende ou compartilha dados pessoais de terceiros. Credenciais e tokens de autorização OAuth são armazenados de forma restrita em variáveis de ambiente protegidas no servidor do aplicativo exclusivamente para execução das postagens autorizadas.

3. Links de Afiliados e Redirecionamento

Ao clicar nos botões de compra exibidos nos cards comparativos (Amazon Brasil, Mercado Livre ou parceiros), o visitante é direcionado diretamente para a plataforma de varejo escolhida. Como participantes do Programa de Associados da Amazon e programas de afiliados parceiros, podemos receber comissão por compras qualificadas, sem custo adicional para o consumidor. As lojas de destino possuem suas próprias políticas de privacidade e cookies.

4. Revogação e Contato

O administrador pode revogar o acesso OAuth a qualquer momento nas configurações de segurança da sua Conta Google (myaccount.google.com/permissions). Dúvidas ou solicitações relacionadas à privacidade podem ser enviadas para: oliveiira2012@gmail.com.
